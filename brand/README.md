# Contest Radar brand

The mark is a radar quadrant sliced into a ranked list: scan, then rank.

| File | Use |
|---|---|
| `contest-radar-symbol.svg` | master symbol, 256 grid |
| `contest-radar-symbol-small.svg` | pixel-snapped cut for 16–32 px (favicon, nav) |
| `contest-radar-horizontal-dark.svg` / `-light.svg` | symbol + wordmark lockups |
| `contest-radar-app-icon.svg` | app icon / avatar / ERC-8004 image (`public/logo.png`) |

Colours: indigo `#5E6AD2` (mark), ink `#F7F8F8` (wordmark on dark), tile `#0F1011`.
Wordmark: Inter SemiBold (SIL OFL 1.1), converted to outlines, so no font is needed.
Keep clear space of one bar height around the mark; don't use it below 16 px.
